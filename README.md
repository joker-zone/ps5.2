# Lea Games

Former project names: **Relapse Installer**, **PS5 WebKit W2JB**, and **evoX W2JB**.

## Installers

- **itsPLK universal installer**: open `Relapse-Installer/index.html`.
- **Lea Games installer**: open `Lea Games/Lea-Games.html`.

Brand assets are stored at the project root: `Cover1.png`, `logo0.jpg`, and `icon.png`. To serve the local pages, run a static HTTP server from the project root.

Use only on devices you own or are authorized to test. The software is provided as-is and may cause system instability or data loss.
